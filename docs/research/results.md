# Results

The `RESULTS_TABLE.md` artifact (auto-generated by our results parsing script) contains the canonical metrics derived from pipeline execution.

## Interpreting the Metrics
- **Macro F1 Score:** The primary metric for classification success, balancing precision and recall across humor categories. This is crucial as humor datasets are frequently imbalanced.
- **Accuracy:** The percentage of correctly classified memes.
- **Parsing Failure Rate:** The percentage of VLM outputs that could not be parsed into valid JSON formats. A high failure rate indicates the VLM struggled to adhere to the required structural constraints.

The strict adherence to empirical data ensures that our results accurately reflect the current state of the pipeline, even if representing early smoke-test data prior to a full dataset run.
