# Project Plan

This document outlines the intended future phases for the project:

1. **Foundation**: Setting up the repository structure, environments, and policies.
2. **Dataset pipeline**: Data collection, cleaning, and preprocessing for Hindi memes.
3. **VLM inference**: Establishing baseline inference using pre-trained Vision-Language Models.
4. **Humor classification**: Fine-tuning or prompting VLMs for humor detection.
5. **Cultural-awareness layer**: Integrating specific cultural context features into the model pipeline.
6. **Classical multimodal baseline**: Implementing standard baseline models (e.g., CNN + RNN/Transformer).
7. **Evaluation**: Comprehensive evaluation using appropriate metrics.
8. **Error analysis**: Detailed breakdown of failure modes and biases.
9. **Gradio application**: Building an interactive web interface for demonstration.
10. **Documentation and research packaging**: Finalizing documentation, reports, and code for release.
